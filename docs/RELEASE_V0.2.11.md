# RapIP v0.2.11：追踪链接与 IP 的前后变化

- **链接变化**：链头显示旧 session → 新 session、旧出口 → 新出口，以及触发原因。点「看工位历次变化」可查看该工位在同一分组中的多次绑定与切换。
- **IP 变化**：搜索或点击 IP，会显示同一资源席位中的实际 Webshare 换号、当前 IP 和状态。池内切换时新链接获配的备用 IP 与旧席位补货得到的新 IP 分开显示。不同席位出现同一个地址时分别列出；缺失的历史不补造。
- 最新事件仍在前；箭头按旧事件 → 新事件，含横向和 Z 字折行。取消未使用的预留会记录为解除预留，不标成换号。旧记录缺少明确原因时，只说明已记录的状态。
- 分组补货和 IP 动态切换弹窗改为紧凑行布局。缺货兜底开关放在方式下方；内容可滚动，保存与取消一直可见。默认随机方式不显示兜底开关。
