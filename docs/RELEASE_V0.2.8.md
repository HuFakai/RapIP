# v0.2.8：代理轨迹、SOCKS 别名与分组补货

- IP 行内复制 SOCKS5 和普通链接弹窗提供 v2rayN 别名：`RapIP-worker-03-<session>-<出口IP>`。未分配显示「待分配」；别名是复制时快照，不会自动更新客户端。API 原有 `links.socks5` 为纯链接，`links.socks5_named` 带 URL 编码片段。
- 代理追踪按链接绑定或 IP/资源席位查看。获配、首次记录连通、session 切换、排空、退役补货和质量准入分别显示。IP 行和工位详情可跳转；绑定轨迹可重新复制当前有效链接。
- 质量分组 → 补货规则：新自动补货任务默认随机。可按组指定国家或 IPv4 CIDR（最多 20 项）；保存不提交换号。任务创建时记录策略快照，既有任务沿用原参数，手动换号沿用该次选择。
- 指定规则先用 Webshare dry run 验证；明确缺货才使用可关闭的随机兜底。真实提交后仅在供应商明确报告缺货且增删均为零时允许一次随机补货，重新检查预算和旧 IP。真实尝试继续计入本地账本；超时、鉴权、额度或结果不明不会触发随机兜底。
- 补回的 IP 继承原分组，仍须准入。替换任务可从旧 IP 轨迹查看规则、兜底、Webshare 任务 ID 和新 IP。

轨迹与绑定状态同事务保存在 SQLite，不含密码、API Key 或完整 URL。沿用事件保留天数，最多 20,000 条。旧记录只导入已有可核实事件及升级时快照。状态 schema 5，回退先备份并恢复旧数据库与镜像。
