# 首版验证记录

日期：2026-11-05。本地环境：macOS、Python 3.13、Node 24。部署环境：Linux ARM64、Docker Compose v5.1.4；管理与代理入口经 SSH 隧道访问。

本轮 UI / 部署更新验证：Python 测试增至 71 项（包含 11 项部署流程测试）；浏览器兼容辅助函数测试 6 项（普通 HTTP 下的 UUID、复制回退及主题保存）。主题选择、完整链接复制、不含密码的 AI 说明复制、SVG 国旗及测活开关均做页面验证。另验证同主机不同端口的登录 Cookie 隔离，避免测试实例使主实例退出登录。

一键部署脚本新增 11 项模拟 Docker 测试，覆盖首次随机凭据/端口、Docker 与系统端口排除、原配置和数据保留、失败重试、并发锁、示例凭据拒绝、Git 拉取与失败中止、构建/健康失败不报成功。Bash 语法检查通过；测试不调用真实 Docker 或供应商。

官方 Docker Compose v5.7.0 的 `config --quiet` 已通过；使用自定义 `19080 / 19081 / 19082` 验证容器监听与宿主机映射一致，健康检查读取环境变量。本地无 Docker 引擎；后续已在 ARM64 服务器完成真实镜像构建与容器部署，见下方记录。

## 已完成

- 域名 HTTPS 反向代理、合法源站证书和安全登录 Cookie 已验证；证书自动续期定时器启用且模拟续期通过。管理监听继续仅本机发布。代理端口改为公网发布，外部 SOCKS5 协商和 HTTP 407 认证响应均通过；连接弹窗由 PUBLIC_PROXY_HOST 显式下发服务器 IP，不再使用 localhost。此次没有新建业务绑定或额外消耗 Replace 额度。
- `uv run pytest -q`：71 项通过，覆盖身份解析、并发独占、粘性、迟到 session、缺货失败、两种切换、故障转移、冷却、重启恢复、单进程所有权、存储故障、鉴权/CSRF/幂等及 SOCKS5、HTTP、CONNECT 转发。
- 整体测活失败不批量烧号；单节点重复失败且同伴可用时进入替换队列；结果不明任务阻止同账号后续替换。
- `uv run ruff check src tests scripts`：通过，源码已格式化。
- `npm run build`：TypeScript 严格检查和 Vite 生产构建通过。
- 浏览器：管理员登录、真实资源/预算展示、模拟工位保留 session 换 IP、模拟补货任务完成、设置保存后重新读取、退出登录均验证通过。
- 390px 窄屏验证无页面级横向溢出，图标导航具备可访问名称，检查时控制台无 warning/error。
- 真实 API Key、管理密码/Token、代理密码未出现在源码、文档或前端产物；本机凭据文件权限为 600。
- ARM64 服务器成功执行一键部署，容器 healthy，鉴权后的 ready 接口返回 true；三个端口只发布到服务器本机，通过 SSH 隧道访问。
- Webshare 6 个 US IP 全部通过服务器只读测活，管理页面显示 6 个可分配资源。
- 真实 SOCKS5（远程 DNS）与 HTTP CONNECT 访问 IP 查询服务成功，同一工位/session 返回同一出口；页面显示真实会话与连接数。
- HTTP CONNECT 在客户端 keepalive_expiry=60 秒时，空闲 8 秒后的第二次 HTTPS 请求复用同一 TCP，出口相同；这属于短时持久连接验证，不代表长期负载测试。
- 页面设置保存、释放临时工位到后端操作回执、真实补货任务完成均验证通过。用户明确授权最多 1 次替换；测试时临时将本地替换预算限制为 1，实际 submitted=1、completed=1、redraws=0。临时会话清理后恢复原预算，原 IP 从供应商列表消失，新 IP 入池；无活跃绑定、无待处理补货。

## 实现取舍

首版采用单调度所有者、SQLite 状态快照事务和每账号串行补货。结果不明任务需供应商后台核对，不提供盲目重试按钮；多用户和分布式能力见独立升级方案。
