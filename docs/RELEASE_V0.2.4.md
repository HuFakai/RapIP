# v0.2.4：账号备注、名称与供应商套餐用量

## 账号信息与操作

添加账号只填写名称、API Key 和选填备注（最多 500 字），ID 由后台生成。旧接口仍可显式传入 ID。网页自动创建使用幂等键导出稳定 ID，网络重试不会新增另一条账号；遇到“ID 已存在”时刷新账号列表核对现状。

备注显示在账号卡片上，并可通过编辑更新。资源池、节点详情、连接详情、任务、事件与分组 IP 选择器均优先展示账号名称；必要时附 ID，历史已移除账号仍显示保留的名称。

编辑、删除、详情等按钮统一使用可见背景和边框，危险操作采用玫红色按钮。账号操作集中为一个按钮组，避免两处自动边距把编辑/删除分散到卡片两端。

## 真实套餐额度与流量

Webshare 官方 API 可以查询套餐更换额度、总流量和当前订阅周期的已用流量。本次实现只读查询：

1. `GET /api/v2/subscription/`：取得当前套餐 ID、订阅开始/结束时间；
2. `GET /api/v2/subscription/plan/{id}/`：读取 `proxy_replacements_total/used/available` 与 `bandwidth_limit`；
3. `GET /api/v2/stats/aggregate/`：明确传入 `plan_id`、`timestamp__gte=subscription.start_date`、`timestamp__lte=当前时间`，读取实际 `bandwidth_total`，不使用未来预估值。

参考：[套餐字段](https://apidocs.webshare.io/subscription/plan)、[订阅周期](https://apidocs.webshare.io/subscription)、[周期聚合](https://apidocs.webshare.io/proxystats/aggregate)、[统计字节单位](https://apidocs.webshare.io/proxystats)。

账号列表优先显示“剩余更换 / 总额度”“剩余流量 / 总流量”、本期已用值、同步时间，以及手动“同步套餐”按钮。**本地替换预算是 RapIP 的独立安全限制，不是供应商余额**，保留在折叠区；更新真实用量不覆盖本地预算、不重置本地提交计数。

- 周期用量由供应商按小时聚合，有延迟。剩余流量按套餐限额减供应商周期实际字节数计算，最低为 0。页面套餐 GB 使用十进制 `1 GB=1,000,000,000 B` 换算；历史转发图表沿用自身的 1024 换算，两类数值用途不同。
- `bandwidth_limit=0` 显示不限量，缺失字段显示待同步；不能把未知当作零额度或无限额。
- 自动用量同步最短间隔 300 秒，跟随账号资源同步；强制同步同账号最短间隔 15 秒。前端普通 GET 读取持久化快照，不直接向供应商高频拉取。查询时长上限 40 秒，不占用关键调度锁。
- 查询失败保留上次数据并标记待更新，不影响节点健康或业务转发；超过 15 分钟未成功同步的数据不计入首页汇总。订阅周期过期后隐藏上期余额，等待新周期同步。
- 当前实现针对账号当前活动套餐；若私有配置显式指定的 plan_id 与活动订阅不一致，显示同步错误，不挪用其他套餐周期的数据。

管理 API：`POST /api/v1/accounts/{id}/refresh-usage` 提交异步幂等同步操作，需要管理鉴权、Idempotency-Key；Cookie 写请求要求 CSRF。API 返回值不包含供应商 Key。失败不会调用 Replace 或修改套餐。

## 首页汇总

新增 IP 更换额度与套餐总流量两张卡片，展示剩余/总量。遍历全部选中账号进行汇总，账号表仅显示前 8 个不影响汇总完整性；当前账号筛选生效，质量组不拆分套餐额度。暂停分配的账号仍属于接入账号，其套餐额度保留在汇总中。

按供应商订阅 ID + 套餐 ID 去重，同一套餐被多个 Key/别名接入不会重复累加。同步失败、缺失或过期则提示仅汇总已同步套餐；所有都未知时显示待同步。包含不限量套餐时明确显示，不把有限流量和无限量强行相加。

本地安全预算仍按账号/全局/质量组等原有规则生效。供应商额度是展示与核对信息，不自动扩大用户授权的本地替换预算。

## 部署

仍使用 Docker Compose 更新，保留私有配置与数据。自动 ID、备注、供应商快照为向后兼容新增字段，无需手动迁移。更新前备份并确认无活跃绑定/连接/替换任务，避免重建中断业务。
