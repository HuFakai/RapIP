# v0.2.3：设置分区、账号维护与易读质量结论

## 设置页

网关设置改为五个页内标签：调度与连接、质量检测源、数据生命周期、外观主题、运行配置。当前标签写入 `#settings?tab=...`，刷新可回到原板块；左右方向键及 Home/End 可切换。已访问板块保留在页面中，隐藏其余内容，切换时不丢失未保存输入；离开设置页或刷新仍会丢弃未保存内容。

## 上游账号

编辑支持显示名称、手动记录套餐流量、当地替换预算与补货国家。账号 ID 不可改，套餐切换仍不支持；编辑不会重置替换计数。

API Key 更新入口默认收起，留空保留原密钥。更新前要求暂停新分配、没有活跃绑定/检测/未完成替换任务；只读校验新密钥能读取节点，并核对现有出口集合一致。校验失败保留原配置；属于其他账号的密钥应使用新 ID 单独添加。

删除是从 RapIP 本地移除，不注销 Webshare、不退订套餐、不调用 Replace、不撤销供应商 Key。界面展示影响、后台是否允许移除，并要求输入账号 ID 确认；需要先暂停账号并结束活跃绑定、排空、检测及未完成/待核对替换。后台归档账号节点并清除私有 JSON 中的 Key、节点代理账密；历史事件、替换计数与删除标识保留，删除过的 ID 不可重新使用，避免计数绕过。仅删除服务器上的当前私有存储，不追溯清理备份或环境变量中的旧密钥。

删除标识先持久化，再更新账号文件；若后续文件清理失败，账号仍被隔离，返回清理提示，重启时重试，不会因残留配置重新分配资源。进行中资源不能强删。

API：`PATCH /api/v1/accounts/{id}` 支持上述资料及可选 `api_key`；`GET /api/v1/accounts/{id}/deletion-check` 查询移除条件；`DELETE /api/v1/accounts/{id}` 提交异步幂等移除操作。都需要管理鉴权，Cookie 写操作要求 CSRF。删除需 `Idempotency-Key`，结果从原 operation 查询。

## 质量报告的直观解释

首页显示家宽场景参考分、类型、证据一致度、使用建议、三个维度与扣分理由。原始来源表和数据默认折叠。旧报告无需重测，读取时使用当前规则计算解释，不修改原始报告，也不改变质量组准入/自动更换。

规则版本 `rapip-house-v1`，**是 RapIP 为严格家宽要求设计的自定义参考指数，越高越适合该场景，不是注册成功率或供应商认证分**。低分的机房 IP 仍可能适合普通连通/采集任务，不能据此判断网络性能差。

### 类型

- 多来源类型或机房标签指向 hosting：显示机房 IP / 机房倾向。
- ISP/家宽类型与机房正向标签同时存在：显示“疑似伪家宽 / 来源冲突”，一致度低；可能是 ISP 代理、机房托管 ISP 或数据库分歧，不能直接证实伪造。
- 只有 ISP/家宽类型且无机房正向标签：显示“家宽倾向（未证实真实家庭线路）”；数据库标签无法核实实际家庭终端。
- 移动、商业/机构网络单独列出；不足证据显示类型未知。组织名称本身不作为硬判据。

“一致度”表示来源标记数量与冲突情况，并非统计置信概率；不同数据库还可能共享数据或经同一查询服务返回，不假设相互独立。

### 计算

综合分 = 信誉参考 × 40% + 家宽适配 × 40% + 风险标签 × 20%，再应用上限：

| 维度 | 规则 |
| --- | --- |
| 信誉参考 | 取 Scamalytics、AbuseIPDB、IPQS 的有效 0–100 原始值中最保守值，用 `100 − 最大值`；不同源含义不等价，这是本地保守排序规则，不是统一风险概率。只有 2 个信誉来源时该维度最高 90，只有 1 个时最高 70；0 个不出该维度分。 |
| 家宽适配 | 家宽倾向 90；移动 75；商业/机构 50；类型冲突 40；机房 20；未知不出该维度分。 |
| 风险标签 | 起点 100，出现 Proxy 减 15、VPN 减 20；Tor 最高 10、滥用或机器人最高 30。IP2Location 原始风险分 ≥75 时此维度最高 50（本地保守阈值）。覆盖少于 3 类风险标签最高 70；完全无风险标签证据则不出该维度分。 |
| 综合上限 | 机房 49、类型冲突 64；信誉来源少于 3 个最高 85、仅 1 个最高 59；明确类型来源少于 2 个最高 69；Tor 最高 20。 |

任何必需维度未知则不显示综合数字，显示证据不足。只识别格式正确且在范围内的分值；`null`、空值、异常值不按 0。ipapi 的公司滥用百分比保持原始显示，不与上述三个信誉分直接混算。所有限制和扣分原因都可在报告中查看。

等级：90–100 优选；75–89 较好；50–74 需要复核；0–49 谨慎使用。分数使用当前已取得的报告证据，不额外查询目标网站，不能推断业务是否成功。

以 104.233.13.67 的截图为例：四个类型来源指向机房，Scamalytics/AbuseIPDB 举报风险低，但 IP2Location 为 91 且有 Proxy/VPN 标签。参考分为 **49/100，机房 IP，严格家宽场景谨慎使用**；信誉维度为 90，不能因此把它判定为真实家宽。

### 来源语义

- [AbuseIPDB FAQ](https://www.abuseipdb.com/faq.html)：分值反映举报恶意活动置信度，0 代表未有理由怀疑，不证明住宅线路。
- [IPQS 文档](https://www.ipqualityscore.com/documentation/proxy-detection-api/overview)：代理/欺诈风险字段与阈值有其自身语义。
- [xykt/IPQuality 数据库检测源码](https://github.com/xykt/IPQuality)：本项目保留原始来源标签，解释层由 RapIP 独立实现。

## 部署

沿用 Docker Compose 更新，保留 `.env`、`config/`、`data/`。升级前确认空闲并备份；重建容器会断开连接。新增删除标识随快照持久化；普通历史清理不能移除该标识或额度账本。
