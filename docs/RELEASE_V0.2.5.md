# v0.2.5：长期绑定与有预算的出口轮换

## 固定配置长期使用

同组、同工位、同 session 的原 IP 长期保留。所有连接断开、长时间不使用、重启都不会让当前 session 因空闲失效或将其 IP 交给别人。不需要保活。改变同一工位的 session，成功取得本组新出口后才替代旧 session；缺货原绑定不变。匿名 session 是独立绑定，建议普通客户端使用稳定 worker。

固定模式的故障自动转移默认关闭；临时故障允许原 IP 重试，供应商移除则标记不可用，原 IP 重新出现会恢复独占归属。故障自动转移可在质量组明确开启，但开启后允许同 session 改变出口。管理页面主动换 IP 或释放同样是显式例外。

只有当前有效 session 长期保留。旧版本已替代/释放的失效配置不会自动复活，已被供应商替换的原 IP 不能找回。旧错误保留历史含义；新错误显示释放/替代原因。

## 质量组出口轮换

在质量组表格点击“固定 IP / 定时轮换”。默认固定，定时需明确开启；周期为 1 分钟到 7 天；无连接暂停为 0 到 7 天，0 代表没有连接即暂停；存在安静 TCP 仍视为使用中。

填写每日和本次授权的有限次数，默认均为 0（暂停，绝不无限）。每日按 Asia/Shanghai 计算。本次总计不因隔天、重连、开关切换或重启重置；重新授权需明确勾选，已有预留时不允许重置。保存策略不立即轮换，首次成功连接后开始一整周期。

无连接超过阈值只暂停计划，保留出口；重连先用原 IP，从恢复时刻计一个完整周期。不补执行错过的轮换。各绑定独立活动；组内每次最多调度一个轮换，已有排空或未完成补货/对账时等待。

平滑切换让新 TCP 走新出口，旧连接最多排空至设置期限；强制关闭旧连接，客户端需重连。不能迁移已建立的 TCP 流。

## 额度与供应商计数

出口切换次数与 Webshare Replace 提交分开显示。自动轮换在切换前预留旧 IP 的补货额度，叠加账号本地、组/全局及供应商余额限制。未知/过期余额不发起新的自动或手动替换；账号“同步套餐”可刷新快照。账号暂停后暂停新的预留提交。

预留、已提交、取消和待对账持久化；未执行的等待请求可取消释放预留。结果不明的 POST 不重放；429 对已预留的参数替换按失败保留，避免重试扩大授权。明确失败的提交仍保守保留本地提交计数，不能把它当作供应商实际扣除。

预算阻塞的既有预留补货在预算恢复后重新核对并继续，不能借新的客户端连接清零预算。额度账本属于关键状态，不随普通日志清理删除。

## 资源池手动更换

可单行“更换 IP”或勾选批量操作。提供保持原国家、指定国家、随机、ASN、IPv4 CIDR 参数，数量锁定为所选 IP 的一换一。库存建议来自对应 Webshare Plan；最终以各套餐预检结果为准，不代表保证真实家宽或业务成功。

先 dry_run，再确认；预检有效期 5 分钟，正式确认会重新核对资源身份、绑定代次、归属与预算，批量预留失败整体不受理。批量内部按账号串行、按 IP 单独提交，方便一换一对账。跨账号不共享密钥或挪动套餐。

默认只操作未绑定资源；没有连接但长期保留的出口仍算已绑定。高级选项允许等待连接全部断开后更换，或明确现在关闭连接、更换供应商 IP、保留 session。等待任务在“任务与事件”查看并可取消；资源/绑定变化自动取消旧请求，需重新预检。

显式更换已绑定出口可能有供应商替换与质量检测的不可用窗口，页面如实提示；新出口继承原质量组，通过检测后才恢复绑定或进入待分配池，失败/未知则保留隔离，不能暗中回退或无限重抽。

## 诊断、设置与管理 API

连接错误区分 ADMISSION_LIMIT（接入处理）、GATEWAY_CONNECTION_LIMIT（全局）、BINDING_CONNECTION_LIMIT（单绑定），说明含建连中的当前值与上限。接入前预留连接槽位，避免明知超限还拨号上游。超限不禁用 session，不触发换 IP。

会话页区分当前传输与空闲保留，支持展开绑定事件。总览显示保留会话及空闲保留数。设置移除空闲回收，容量可配最大保留绑定数、最少备用 IP；默认不再隐式限制为 60%。不留备用时所有 IP 可绑定，但无法保证立即轮换。

运行配置显示公网代理地址和映射端口，高级信息保留监听地址；故障策略按组，不再显示写死的开启状态。AI 接入说明同步新的长期配置和轮换语义。

新增鉴权接口：

- PUT /api/v1/groups/{id}/rotation：保存出口策略，可显式 ?reset=true 重新授权本次总额；普通保存不清零。
- GET /api/v1/accounts/{id}/replacement-options：脱敏库存建议，服务端缓存 60 秒；失败返回提示，绝不回传供应商凭据。
- POST /api/v1/replacements/preview：节点列表、selection、bound_action，提交异步供应商预检。
- POST /api/v1/replacements/commit：preview_id，受理等待请求。
- GET /api/v1/replacements/requests：等待请求与其替换状态。
- POST /api/v1/replacements/requests/{id}/cancel：只取消未执行请求。
- GET /api/v1/events?binding_id=...：绑定事件。

写接口沿用管理鉴权、Cookie CSRF、Idempotency-Key 和异步 operation 查询。不会通过页面 GET 发起真实 Replace。

备份私有环境、配置、数据库和旧镜像，再 Docker Compose 更新。schema 3；需要回退时停服务并恢复整套旧状态。生产不为了验收额度写路径而消费真实 Replace，使用模拟供应商覆盖。定时计划与故障转移不会自动开启。
