# IP 资源池链接与工位规则（v0.2.6）

状态：已实现，2026-11-06。此规则替代此前关于行内待用链接不锁定 IP 的讨论稿。

## 两种入口

| 入口 | 是否立即绑定 IP | 重复复制 | 首次连接 |
| --- | --- | --- | --- |
| IP 行内 SOCKS5 / HTTP，当前待分配 | 是，立即预留该 IP / 工位 / session | 两种协议共享同一真实绑定 | 原 IP 转为使用中 |
| IP 行内 SOCKS5 / HTTP，当前使用中或空闲保留 | 已有绑定 | 复制真实 country / group / worker / session，不轮换 | 继续使用原绑定 |
| 右上角复制代理链接 | 否，只生成普通待用身份 | 未使用前保持同一份，使用后生成下一份 | 从对应组中选取合格待分配 IP |

所有链接都使用 RapIP 服务器入口与代理密码，绝不导出供应商凭据。复制不是业务连接，不调用 Replace。链接含真实密码，勿写进日志、Git 或公开聊天。

## 预留生命周期

- 新增 RESERVED 状态，界面为“已预留·待连接”，节点 used=false。
- 预留立即退出待分配池，其他工位不能占用；持久化到 schema 4，断连与进程重启不回收。
- 同身份首次通过网关申请连接时转为 IN_USE / used=true；此后使用 v0.2.5 的长期保留规则。目标连接失败也不自动清空已启用身份。
- 取消未使用预留使旧 session 失效，IP 按原组当前质量准入退回待分配或隔离，无黑名单、无 Replace、无额度扣减。
- 取消接口在同一锁内确认仍未使用。连接先完成时拒绝取消，避免误执行已使用绑定的释放。
- 改 session 时先申请新合格库存；无库存保留旧绑定。若旧预留未使用，解除旧预留不退役该 IP；已使用旧出口仍按轮换规则处理。
- 替换中、隔离、排空节点不能通过复制绕过准入；隔离节点仍允许独立只读质量报告。

## 普通待用配置与工位

- 每组缓存一份未使用的普通配置；它只占一个待用身份，不占 IP / 活跃绑定额度。
- 首次使用后消耗该待用身份；下一次复制选择另一空闲工位。绑定、预留、已撤销身份不会被当成未使用配置复用。
- 所有 IP / 工位均已占用或触及绑定、热备限制时，返回 NO_PENDING_LINKS：“无待用链接，请点击 IP 行内 SOCKS5／HTTP 复制对应链接”。不抢占已有连接。
- 若普通待用身份对应空闲工位，而用户随后显式预留一行 IP，该身份可以用于此显式预留，两种入口不会产生同工位的竞争 session；此后再次生成普通链接会选择另一个空闲工位。
- 自动生成 worker 为 01～N；N 初始取组内 IP 数量，随扩容增长，缩容保留历史最大范围；不保证每个编号随时都有可分配库存。
- 新组默认启用受管规则，只接受范围内规范编号；原有组默认兼容。可在“复制代理链接 → 工位规则”切换。
- 启用规则不会撤销已有自定义 worker 或匿名绑定。新匿名/越界工位被拒绝；有效工位改变 session 仍是正常换 IP 操作。
- 完整 URL 只在认证后的复制响应里返回，不写入操作结果、审计或状态快照；幂等重试仅持久化无密码的路由身份。

## 管理 API

- POST /api/v1/proxy-links，JSON `{ "node_id": "<ID>" }` 显式预留 / 复制真实绑定；JSON `{ "group_id": "default" }` 获取普通待用配置。支持 Idempotency-Key，同一键重试返回同一身份；不生成异步操作以免将完整密码写入操作记录。
- POST /api/v1/bindings/<ID>/cancel-reservation，异步幂等操作；只有尚未使用的预留可取消。
- PATCH /api/v1/groups/<ID>/workers，JSON `{ "managed": true }`。GET /groups 的 workers 字段显示容量、占用与模式。
- 所有写入保留 Cookie CSRF / Bearer 认证；普通节点列表不会生成身份或改变绑定。
