# v0.2.9：分组补货库存选择

质量分组的补货规则支持随机、保持原国家、指定国家、指定 ASN、指定 IPv4 CIDR。指定项由 Webshare 计划库存提供，搜索只筛选已有选项；国家单选、ASN 和号段最多 20 项。

跨账号分组只提供每个启用上游账号共同可用的选项，显示各账号中的最小库存。保存时用同一供应商库存快照（最多缓存 60 秒）和最新的分组账号范围重新验证。库存不可读或选择已不在共同库存中时，不能保存指定目标；执行仍以 Webshare 预检为准。已有规则不自动修改。保存不提交真实替换。

当前动态切换行为不变。保持原国家时按退役 IP 的国家生成供应商规则；若旧 IP 国家未知，任务停止并提示原因。
